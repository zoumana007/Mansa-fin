# 78 — Site Web Public Mansa : présentation de la marque, produits, chiffres clés, tarifs, partenaires, sécurité, investisseurs, carrières, support, téléchargement et administration centralisée

## 1. Objet du document

Ce document définit le cahier des charges complet du **Site Web Public Mansa**.

Le site constitue la vitrine officielle de Mansa auprès :

- du grand public ;
- des clients ;
- des commerçants ;
- des agents ;
- des entreprises ;
- des établissements scolaires ;
- des administrations ;
- des banques ;
- des opérateurs Mobile Money ;
- des partenaires techniques ;
- des développeurs ;
- des investisseurs ;
- des médias ;
- des candidats ;
- des autorités.

Il doit permettre notamment :

- présenter Mansa ;
- présenter la vision ;
- présenter les produits ;
- expliquer le fonctionnement ;
- afficher les pays disponibles ;
- afficher les tarifs ;
- afficher les chiffres clés ;
- présenter la sécurité ;
- présenter les partenaires ;
- orienter vers les applications ;
- permettre le téléchargement ;
- présenter les services Client, Commerce, Agent et TPE ;
- présenter le réseau GAB/DAB ;
- orienter vers le portail Développeurs ;
- orienter vers les portails spécialisés ;
- présenter les offres Entreprises, Éducation et Institutions ;
- publier les actualités ;
- publier les communiqués ;
- publier les offres d’emploi ;
- fournir une FAQ ;
- permettre de contacter Mansa ;
- afficher les pages légales ;
- publier l’état des services ;
- collecter des demandes de partenariat ;
- collecter des demandes de démonstration ;
- gérer la communication investisseurs ;
- administrer tous les contenus depuis le back-office.

Le site doit être :

- moderne ;
- haut de gamme ;
- rapide ;
- animé avec sobriété ;
- responsive ;
- accessible ;
- multilingue ;
- multi-pays ;
- administrable ;
- optimisé pour les moteurs de recherche ;
- sécurisé ;
- compatible avec les réseaux faibles ;
- capable d’évoluer avec le projet Mansa.

---

# 2. Principes fondamentaux

## 2.1 Le site ne doit pas être une simple brochure

Il doit servir à :

- informer ;
- rassurer ;
- convertir ;
- orienter ;
- recruter ;
- documenter ;
- soutenir les ventes ;
- soutenir les partenariats ;
- valoriser la marque ;
- publier les résultats officiels.

## 2.2 Les chiffres doivent être fiables

Les chiffres publics doivent provenir de sources validées.

Exemples :

- nombre d’utilisateurs ;
- volume de transactions ;
- nombre de commerçants ;
- nombre d’agents ;
- nombre de TPE ;
- nombre de GAB/DAB ;
- pays couverts ;
- taux de disponibilité ;
- emplois créés ;
- partenaires.

Aucun chiffre ne doit être publié sans :

- source ;
- date ;
- propriétaire ;
- validation ;
- contexte ;
- historique ;
- statut de publication.

## 2.3 Les tarifs doivent être transparents

Le site doit afficher clairement :

- frais clients ;
- frais commerçants ;
- frais Agents ;
- frais TPE ;
- frais cartes ;
- frais retraits ;
- frais transferts ;
- conditions ;
- exceptions ;
- date d’effet.

## 2.4 Tous les contenus doivent être administrables

L’administration doit pouvoir modifier :

- textes ;
- images ;
- vidéos ;
- chiffres ;
- tarifs ;
- liens ;
- produits ;
- partenaires ;
- pays ;
- langues ;
- pages ;
- menus ;
- formulaires ;
- actualités ;
- offres ;
- FAQ ;
- campagnes ;
- bannières ;
- documents.

## 2.5 Le site doit s’adapter aux pays

Chaque pays peut avoir :

- sa langue ;
- ses produits ;
- ses frais ;
- ses partenaires ;
- ses moyens de paiement ;
- ses pages légales ;
- ses contacts ;
- ses offres ;
- ses chiffres ;
- ses applications ;
- ses restrictions.
